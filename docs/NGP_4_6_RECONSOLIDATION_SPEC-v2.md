## 1. Парадигмальный сдвиг: От мёртвого RAG к Живым Фазовым Энграммам

Классическая парадигма **Retrieval-Augmented Generation (RAG)** рассматривает контекст как «выборку статических файлов с жёсткого диска». Операция чтения в традиционных векторных базах данных (Faiss, Milvus, Qdrant) является пассивной: запрос $q$ ищет ближайшие эмбеддинги по косинусному расстоянию в мёртвом векторном пространстве, не меняя состояние самой базы.

Архитектура **NGP 4.6 (Generative Engram Architecture)** имплементирует фундаментальные открытия когнитивной нейробиологии (Шактер, Либет, Надер, Райсл), подчинённые неэрмитовой квантово-подобной топологии:

1. **Конструктивная симуляция вместо поиска (Schacter-Loftus):** Память не хранит законченные текстовые фрагменты. Знание локализовано в виде координат фазовых аттракторов на многообразии Грассмана $G(4, \mathbb{C}^{64})$. Запрос генерирует актуальный контекст «на лету» через фазовую релаксацию.
2. **Потенциал готовности (Libet-Haynes / DMN):** Кольцевой буфер в `/dev/shm` работает как Default Mode Network (DMN), непрерывно просчитывая перцептивные траектории и снижая задержку активации оракула $O(1)$ до $p99 < 1.7\ \mu\text{с}$.
3. **Реконсолидация при считывании (Nader-LeDoux):** Каждая операция извлечения энграммы кратковременно переводит фазовые веса в **лабильное (пластичное) состояние**, перезаписывая синаптический след с учётом текущего контекста и элиминируя «галлюцинации» и овершед.
4. **Предиктивный нейро-драйвер пластичности (Google TimesFM-200M Sidecar):** Скорость затухания $\lambda$ и коэффициент нейропластичности $\eta$ управляются не статическими константами, а фоновым прогнозом вероятностных всплесков актуальности (Temporal Bursts) через асинхронный сайдкар Google TimesFM-200M.

## 2. Математическая модель лабильных энграмм & TimesFM Предиктивная Нейропластичность

### 2.1. Динамика фазового состояния и изолокация на $G(4, \mathbb{C}^{64})$

Энграмма в субстрате NGP 4.6 описывается векторным фазовым состоянием $\mathbf{\psi}(t) \in \mathbb{C}^{256}$ под управлением эффективного неэрмитова Гамильтониана $\hat{H}_{\text{eff}} = \hat{H}_0 - i\hat{W}$.

> **Изоморфизм пространства состояний:**
> $$\mathbb{C}^{256} \cong \bigoplus_{k=1}^{4} \mathbb{C}^{64} \quad \text{или} \quad \mathbb{C}^4 \otimes \mathbb{C}^{64}$$

Уравнение движения:
$$\frac{d\mathbf{\psi}(t)}{dt} = -i \hat{H}_{\text{eff}} \mathbf{\psi}(t) + \mathbf{\Gamma}_{\text{recon}}(\mathbf{\psi}, \mathbf{q})$$

### 2.2. Окно лабильности $\tau_{\text{labile}}$ и масштабирование на CPU

Фундаментальный физический предел для фотонного субстрата TFLN ($\text{LiNbO}_3$):

$$\tau_{\text{phys}} = \frac{1}{\gamma_0 - \gamma_{\text{scat}}} \approx \frac{1}{8.1 \times 10^9 - 1.188 \times 10^7} \approx 123.6\ \text{пс}$$

**Масштабирование на CPU/AVX-512:** Один такт при 3 ГГц $\approx 333\ \text{пс}$, поэтому прямое отмерение $\tau_{\text{phys}}$ невозможно. В программной эмуляции окно лабильности моделируется как атомарная lock-free CAS-секция с порогом деградации пластичности:

$$\tau_{\text{soft}} = \kappa \cdot \tau_{\text{phys}}, \quad \kappa = \frac{f_{\text{CPU}}}{f_{\text{photonic}}} \approx \frac{3 \times 10^9}{8.1 \times 10^9} \approx 0.37$$

### 2.3. Алгоритм перезаписи весов с предиктивным драйвером Google TimesFM-200M

**Архитектурное разделение контуров (Fast Path / Slow Path):**

- **Slow Path:** Фоновый сайдкар Google TimesFM-200M анализирует вектор временных интервалов доступа и каждые $T_{\text{sidecar}}$ секунд записывает скалярный прогноз $\hat{y}_{\text{burst}} \in [0, 2]$ в `/dev/shm/ngp_timesfm_burst.raw`.
- **Fast Path:** Микросекундное ядро делает O(1) чтение из shared memory — без накладных расходов трансформерного инференса.

Уравнение реконсолидации с клиппингом нормы:

$$\mathbf{W}_{\phi}^{(t+1)} \leftarrow \mathbf{W}_{\phi}^{(t)} + \eta_{\text{eff}} \cdot \left( \mathbf{\psi}_{\text{retrieved}} \otimes \mathbf{q}_{\text{context}}^\dagger \right) \cdot e^{-\lambda_{\text{eff}} \cdot \Delta t}, \quad \|\Delta W\|_F \le \delta_{\max}$$

Где:
- $\eta_{\text{eff}} = \eta_0 \cdot (1 + \alpha \cdot \hat{y}_{\text{burst}})$ — предиктивная пластичность из сайдкара;
- $\lambda_{\text{eff}} = \lambda_0 \cdot \exp(-\beta \cdot \hat{y}_{\text{burst}})$ — затухание Эббингауза;
- $\delta_{\max} = 0.05$ — жёсткий клиппинг для гарантии радиуса сходимости Ньютон-Шульц.

## 3. Поток данных: Generative Engram vs. Classical RAG

```
[ Традиционный RAG ]
Запрос q --> [Косинусный поиск O(N)] --> [Мёртвые токены] --> Ошибка/ГАП

[ NGP 4.6 Generative Engram ]
Запрос q --> [TimesFM Sidecar O(1) read /dev/shm]
         --> [Фазовая Релаксация G(4,C^64)]
         --> [Низкоранговая Реконсолидация W_phi + клиппинг]
         --> Живой Контекст
```
