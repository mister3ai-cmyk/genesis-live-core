## Текущее представление памяти
- **Основной режим — многовекторная 4-гранная память.** Каждый узел — до 4 граней F0–F3 × 128 float32, без ортонормализации. Маска присутствующих граней `face_mask` лежит в 64-байтном заголовке.
  - Ingest по умолчанию пишет только F0. F1/F2 приходят от источника или позже от LLM (enrich hook).
- **Скорер AUTO:**
  - B5 = Σ_f⟨q, F_f⟩² в однородной арене;
  - знаковый max-sim B4 в смешанной.
- **Индекс:** FACEWISE_FOLDED SRP 256 бит, pool 768.
- **Режим Грассмана G(4, ℝ^128)** (MGS, O(4)-инвариантный хэш SUBSPACE_ENERGY, гейт A2 по октантам) — **экспериментальный**. Он остаётся в коде как опция (`orthonormalize=True`, `hash_mode`, `HG_A2_INVARIANT`), но не используется по умолчанию. По §6 «Б» он кандидат только для v2 с метаданными.
- **Боевой контур** (время, замещение фактов с учётом доверия, стресс-тест ANIS, реконсолидация, MCP-адаптер) — в репозитории genesis-l0, ветка `feat/ngp46-combat`, слита в локальный master. Сводка с источником каждого числа — `genesis-l0/hologlyph/TECHNICAL_SUMMARY.md`.
